# Clare Homes, concept site

A pitch mockup for Clare Homes (Isaac Scott and Kendall Gilmore, Lafayette, LA), built by Andrew Young under Foundation Code.
Same content as clare-homes.com, rebuilt mobile first and aimed at local search: "FORTIFIED home builder Lafayette LA",
"custom home builder Lafayette", "zero energy ready home Louisiana".

Live (link only): https://achyboy.github.io/clare-homes/

## How it works
- `build.py` writes all six pages (`index`, `fortified`, `zero-energy-ready`, `projects`, `about`, `contact`) from one shared shell.
  Edit page copy there, never in the .html files.
- `data.js` holds the projects, photos, alt text and client quotes. `extras.json` holds the one off photos and logo sizes.
- `site.css` / `site.js` are shared. The music player and the always fresh head script are copied by `build.py`
  straight out of `~/Development/louisiana-bean-site/index.html`.
- Deploy ONLY with `./deploy.sh "message"`: it builds, stamps one build number into every page and `version.json`, commits and pushes.
  Add `?debug=1` to any page for the music log.

## Before it goes live on clare-homes.com
- Remove `<meta name="robots" content="noindex, nofollow">` (in `build.py` head) and change `robots.txt` to allow crawling.
- Remove the "Concept preview by Foundation Code" pill (`.demo-tag`).
- Add a canonical link and sitemap.xml pointing at clare-homes.com.
- 🔴 Confirm rights to the Keaty Real Estate drone footage (`video/hero.mp4`, `video/roof.mp4`, `video/film.mp4`, all carry a KEATY watermark), or get clean files from Isaac.
- Confirm the business has a street address to add to the JSON-LD (his site lists none, so only city/state is used).
